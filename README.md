# 语麦 SayMic

语麦是一款 Windows 语音输入工具。用小米 RC001 蓝牙遥控器按住说话，也可以把遥控器按键映射到常用快捷键。公测版适用于 Windows 10 1809 及以上和 Windows 11 的 64 位电脑。

**[前往官网下载 Windows 版](https://renxbl.icu/intro/#download)**

## 可以做什么

- **语音打字**。配置语音输入工具后，按住语音键说话，将文字输入当前有光标的窗口。
- **按键映射**。把遥控器按键设置成常用快捷键，适合演示、媒体和日常操作。
- **小麦 AI**。登录语麦账号后，可用小麦对话。按需启用微信、办公文档和电脑控制。
- **微信附件**。按指令查找附件、打开文件，或提交到本机打印机。

## 怎样选择安装包

- **整合版**随安装提供小麦和虚拟声卡，适合首次体验完整功能。
- **拆分版**先安装语麦和输入法配置助手，可以在应用内按需添加小麦和遥控器组件。
